# Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using **HTML, CSS, and JavaScript**.

This project demonstrates the use of DOM manipulation, event handling, and basic game logic in JavaScript to create a fun browser-based game.

---

## 🎮 Project Overview

This Rock Paper Scissors game allows a user to play against the computer. The user chooses one option (Rock, Paper, or Scissors), and the computer randomly selects its choice. The game then determines the winner based on standard rules:

- Rock beats Scissors  
- Scissors beats Paper  
- Paper beats Rock

Results are displayed in real time with scores.

---

## 🧠 Technologies Used

- **HTML** – For structure and layout  
- **CSS** – For styling and responsive design  
- **JavaScript** – For game logic and interactivity  
- **DOM Manipulation** – To update UI dynamically
